# The First Legacy — 첫 번째 장인의 흔적

[콘텐츠 MVP](README.md) · [성장 체계](../system/PROGRESSION.md) · [장인의 도감](../system/SMITHS_CODEX.md) · [첫 탐험](../system/FIRST_EXPEDITION.md)

## 왜 필요한가

기존 제작→판매→골드→효율 증가 루프만으로는 **플레이어가 무엇을 이루었는지, 만든 무기가 왜 의미 있는지** 보상이 약하다. 시스템의 수보다 **제작한 물건이 마을과 바깥 세계에 남기는 흔적**을 우선한다.

### 핵심 보상 3축

1. **Smith's Codex:** 어떤 도구·무기를 만들고 이해했는가를 수집한다.
2. **Masterwork record:** 판매/양도 뒤에도 최고 제작 품질·대표 작품·현장 평가가 영구 기록된다.
3. **World Progression:** 주민의 생산·탐험가의 귀환·새 공급품/지역 접근 등 세계가 단계적으로 변화한다.

큰 전투 장면, 직접 조작, RPG 파티 육성은 필요하지 않다. 작은 하단 대장간의 아늑한 경험을 보존한다.

## First Legacy 플레이 체인 — 확정 방향, 콘텐츠 순서 초안

1. 기존 설비를 소유한 대장장이가 주민의 **실제 생활 도구** 주문을 받는다.
2. Chef Kitchen Knife / Farmer Rake / Leatherworker Punch / Carpenter Hatchet 등 제작을 통해 기술 숙련이 오른다.
3. 관련 연구 트리 노드가 발견·진행되고, 첫 Dagger/Spear/Push Dagger/Hand Axe 등 기본 무기 제작법이 차례로 열린다.
4. 제작물은 Codex에 최초 제작, 최고 품질, 기술 기여, 사용 후 보고를 남긴다.
5. 외부 Hunter의 Hunting Knife 또는 Bow & Arrows 요청으로 **기본 무기 제작**을 체험한다.
6. Hunter를 **첫 일회성 탐험가**로 고용하고 플레이어 제작 무기·식량을 선택적으로 준비하여 오래된 숲길에 파견한다.
7. 귀환 시 Hunter가 장비의 **구체적인 쓰임과 아쉬운 점**을 이야기한다. 무기 현장 평가는 실제 계산 결과에 근거한다.
8. 숲길의 위협 완화 등 소규모 세계 상태 변화가 새 재료/주문/다음 목표로 연결된다.

**튜토리얼** 3개 적격 제작/주문 이내 이해도 Lv.1 보장은 보존한다. 위 첫 의뢰의 정확한 등장 순서와 요구 품목은 플레이테스트 조정 대상이다. 고급 제작법을 단순 반복 XP만으로 자동 지급하지 않는다.

## 구현용 얇은 수직 슬라이스

전체 콘텐츠를 동시에 구현하지 않는다.
- **Slice A:** Chef의 Kitchen Knife → Blade Forging·Handle Fitting XP → Dagger 연구 노드 → Dagger 제작 및 Codex 등록.
- **Slice B:** Farmer의 Rake → Hafting·Point Forging → Spear 발견·연구.
- **Slice C:** Hunter의 Bow/Arrows → 일회성 오래된 숲길 파견 → 장비에 근거한 귀환 대화 → 지역 상태 변화.

다른 주민 주문 1종씩은 콘텐츠 확장 단계로 추가하되 4명 모두 실제 주문 가능 상태까지 구현한다. 첫 기본 무기의 정확한 해금 조건·밸런스는 조정 데이터로 관리한다.

## 관찰해야 할 재미/UX 지표

첫 의뢰 완료, 최초 제작법 발견, 최초 무기 제작, 실제 무기 현장 평가 도달, 돌아와서 다음 목표 선택, 무기 재제작 여부를 이벤트로 측정한다. XP 팝업만으로 보상을 대신하지 않는다. 반복 제작에 단순 보상만 누적되어도 재미없어지는지를 실제 플레이로 검증한다.

## 제외

카드 29종 전체 구현, 60무기 도감 채우기, 온라인 마켓/Steam Market, 탐험 전투 영상, 다중 파티/영구 고용, 도구 내구도 물리 시뮬레이션, 별도 3D 월드.
