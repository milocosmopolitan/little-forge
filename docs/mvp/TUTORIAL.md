# Tutorial — 첫 주민 주문과 연구 발견

## 확정된 학습 경험

주민이 대장간에 찾아와 **한 계열의 무기 또는 도구 3개를 주문**한다. 제작할 때마다 관련 경험을 받고, 이해도는 확률적으로 상승하지만 **세 번째 완료 이내 이해도 Lv.1이 반드시 해금**되어 첫 연구 노드를 발견한다. 첫 튜토리얼 주문은 통상의 30~60분 의뢰 주기를 기다리지 않는다.

시각적 튜토리얼은 게임을 독점하지 않고 관리 UI로 이어지며, 처음부터 기초 설비와 작업 경험이 있는 대장장이를 보여준다.

## 제안된 순서 (유저가 챕터·정확한 품목을 최종 확정한 것은 아님)

1. 농부의 낫 수리: 기존 도구 제작/수리, 마을 관계 소개.
2. 경비병의 검 3자루 주문: 제작 큐·숙련도·확률적 이해도·Lv.1 보장·기초 검 연구.
3. 재료 부족 시 농장/목공소/잡화점에서 구매: 골드·재료 공급 UI.
4. 모험가에게 제작 무기를 제공하고 탐험대 파견: 재료 회수/타이머.
5. 떠돌이 상인의 카드 소개와 동일 카드 합성: **카드 시스템 출시 시 후속 튜토리얼**. Foundation 필수 아님.
6. 생활 루프: 피로 누적 → 자동 수면 → 기상 후 음식 창고 자동 섭취, 무료 우물물; Needs 기능 도입 시 자연스럽게 소개.

기존 설계에는 처음 3개 주문이 검 3개인지 또는 주민 도구 3개인지 표현의 차이가 있다. **'동일 연구 분야 관련 주문 3회 이내 Lv.1 보장'이 확정된 메커니즘**이고, 구체 첫 아이템과 등장 순서는 콘텐츠 결정 사항이다.

## 완료 조건

- 신규 유저가 설명 없이 첫 작업 등록→완료→보상→연구 발견을 경험.
- 세 번째 적격 완료까지 Lv.1 보장(재실행으로 확률 재추첨 불가).
- 기본 도구와 무기 작업이 혼동되지 않으며 완료·납품·판매를 구별.
- 인터럽트/창 접기/종료 후 튜토리얼 상태 복구.
- 무리한 대기, 강제 포커스, 재료 부족 소프트락 없음.
