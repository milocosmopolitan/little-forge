# Experience — 경험·이해도·발견형 연구

[홈](../../README.md) · [제작](CRAFTING.md) · [NPC 관계](NPC_RELATIONSHIP.md)

요청한 파일명 `EXPRIENCE.md`를 유지한다.

**확정 방향:** 제작하며 이해도를 얻고, 이해도를 기반으로 발견형 연구를 해금한다. NPC가 도구를 사용하고 준 피드백이 경험·이해도·연구 성장으로 연결된다. 튜토리얼 주문 3개로 이해도 Lv.1을 보장하는 방향이 이전 기획에 있다.

## 성장 요소

| 요소 | 의미 | 획득 방향 | 역할 |
|---|---|---|---|
| 제작 경험 | 대장장이의 전반적 숙련 | 제작·수리 완료 | 전반 성장 |
| 이해도 | 특정 도구·무기·재료·기술의 이해 | 제작 중 발견·실사용 피드백 | 관련 연구 기회 |
| 연구 경험 | 연구 진행에 기여하는 지식 | 새 문제·피드백 분석 | 기술·제작법 연구 |

세 요소를 구별하는 방향을 유지한다. 제작 경험을 완료마다 확정 지급하고 이해도를 확률 획득으로 나누는 방식은 이전 설계안이다. 사용자 발언의 확률적 성장 방향을 반영하되 모든 XP를 무조건 동일한 확률로 처리한다고 단정하지 않는다.

이해도는 거래 가능한 화폐가 아니다. 연구 해금 자격, 연구 진행량, 연구 완료는 별도 상태다.

## 제작에서 연구로

1. 주문·제작·수리를 수행한다.
2. 해당 분야의 제작 경험·이해도 조건을 갱신한다.
3. 관련 단서가 있으면 연구 기회가 발견된다.
4. 연구 조건·재료·진행 요구를 확인한다.
5. 연구 완료 후 실제 제작법·기술을 사용할 수 있다.

튜토리얼에서는 관련 주문 3개 이내에 이해도 Lv.1을 보장한다. 정확히 어떤 무기/도구 계열을 사용할지와 확률값은 미정이다. 매번 운이 나빠 연구가 열리지 않는 상황을 막기 위한 보장이다.

일반 구간의 연속 실패 보정은 설계안이며 보장 횟수는 미정이다. 실패 보정 상태·튜토리얼 완료 기록·RNG는 저장해야 재시작으로 동작이 달라지지 않는다.

## NPC 사용 피드백

**확정:** 공급한 도구를 사용해본 NPC의 피드백을 통해 경험과 연구 성장을 얻는다. 실제 마모나 작업 물리는 계산하지 않는다.

예: 목수의 “단단한 목재에서 날이 쉽게 무뎌진다”는 보고 → 절삭 도구 이해도·열처리 연구 단서. 이 대사와 보상량은 콘텐츠 예시다.

| 출처 | 피드백 주제 후보 | 연결 분야 후보 |
|---|---|---|
| 목수 | 예리함·균형·정밀도 | 절삭 구조·정밀 가공 |
| 가죽세공사 | 작은 날의 정확도·마모 | 정밀 단조·날끝 |
| 농부 | 충격·녹·강도 | 열처리·방청·강도 |

### 전달 설계안

납품 ID와 피드백 템플릿을 연결 → 사용 기간 이벤트 대기 → 자격 확인 → 장부 자동 기록 → 보상 한 번 지급.

읽기 버튼을 눌러야 연구 경험이 지급되도록 강제하지 않는다. 같은 납품 보고의 재전달은 보상을 추가 지급하지 않는다. 첫 발견의 보상과 반복 피드백 보상을 구별하며 반복 상한·감쇠 값은 미정이다.

피드백을 받을 도구 납품이 없으면 피드백을 무작위 생성하지 않는다. [경제 스케줄러](ECONOMY.md)와 별도의 자격 목록을 사용한다.

## 연구 분야

무기 종류·제련 재료·기술·마법/속성으로 분리하는 구상은 이전 설계안이다. 생활 도구의 지식을 무기 연구에 이어 사용하는 방향을 유지한다. 농기구의 곡날 가공 → 곡날 무기, 목공 도구의 정밀 가공 → 단검 연구 등은 연결 예시다.

연구 단서 발견이 곧 완제품 지급·즉시 제작 가능을 뜻하지 않는다. 구체 연구 노드·트리·시간·비용은 미정이다. 초기에는 소수 피드백과 발견만으로 루프를 검증한다.

## 최소 저장과 검증 — 설계안

분야별 XP/이해도, 해금된 연구, 연구 진행, 발견한 단서, 피드백 처리 ID, 튜토리얼 보장 상태를 저장한다.

동일 납품의 보상 1회, 관련 없는 연구 오해금 방지, 3개 주문 후 Lv.1 보장, 연구 발견과 완료 구분, 저장 후 확률·보장 상태 복원을 검증한다. 레벨 곡선·XP 값은 조정 전이다.
