# NPC Relationship — 관계·의뢰·납기

[홈](../../README.md) · [NPC](../npc/README.md) · [경제](ECONOMY.md) · [경험](EXPRIENCE.md)

## 확정된 관계

NPC별 호감도는 0~100이다. 주민 도구의 수리와 제작 의뢰에는 데드라인이 있고, 결과가 호감도에 영향을 준다. 호감도는 거래 가격과 연결된다. 특정 도구 공급은 상점의 새로운 상품을 해금한다.

호감도 증감량·단계 구간·할인율·실패 손실은 미정이다. 이전의 성공 +3·실패 -2 등은 예시다.

## 의뢰 상태 — 설계안

| 상태 | 의미 | 다음 전이 |
|---|---|---|
| 제안됨 | 의뢰함에서 조건 확인 | 수락 / 거절 / 만료 |
| 수락됨 | 계약·납기 시작 | 재료 확보·큐 등록 / 취소 / 실패 |
| 작업 중 | 지정 제작·수리 수행 | 납품 준비 / 실패 |
| 납품 준비 | 요구품 확보·예약 | 납품 / 실패 |
| 완료 | 납품 인정·보상 지급 | 종료·필요 시 피드백 대기 |
| 실패·취소·거절·만료 | 이유를 기록한 종료 | 종료 |

작업 완료와 납품 완료를 구별한다. 자동 납품 허용 여부는 미정이다. 자동 납품을 채택하면 완료 시 계약을 충족한 시점을 납품 시각으로 저장한다. 수동 전달을 채택하면 플레이어의 확인 지연이 방치 경험을 해치지 않도록 유예 등 정책이 필요하다.

## 납기

**설계안:** 수락 전에는 납기 카운트다운을 시작하지 않는다. 미수락·거절·만료를 수락 후 실패와 같은 불이익으로 처리하지 않는다.

| 유형 | 제안 납기 | 상태 |
|---|---|---|
| 일반 수리 | 수락 후 2시간 | 조정값 |
| 신규 도구 제작 | 수락 후 4시간 | 조정값 |
| 긴급 의뢰 | 수락 후 45분 | 선택 확장, 초기 필수 아님 |

30~60분은 이벤트 생성 간격이다. 납기와 같지 않다. 초기의 10분 긴급·30분 일반 예시보다 방치 경험에 맞춘 위 제안을 우선 검토한다.

납기 시계는 [아키텍처](../../ARCHITECTURE.md)의 활동 시간 모델을 권장한다. 절전·종료 동안 수락 의뢰의 납기를 멈추고 제작·탐험은 제한된 범위에서 진행하는 설계안이다. 확정 정책은 플랫폼 POC 뒤 정한다. 시간 정책 변경 시 관련 문서를 함께 갱신한다.

## 수락 계약

수락할 때 NPC·요구 작업/품목·수량·재료 안내·보상·호감도 변화·납기를 명시한다. 수락 이후 가격 변화나 템플릿 수정이 기존 계약을 소급 변경하지 않도록 스냅샷을 저장하는 설계안이다.

의뢰 수락은 재료 소유와 다르다. 재료가 부족하면 상점 구매·탐험을 선택한다. 수락 상한과 예상 작업 시간을 표시해 선택을 돕는다.

## 실패와 회복 — 설계안

수락 후 납기 실패에는 약속한 관계 영향을 한 번 적용한다. 관계를 0~100으로 제한한다. 일일 손실 상한·취소 손실·실패 보상은 미정이다.

관계 하락이 기본 재료·회복 의뢰 접근을 완전히 막지 않도록 한다. 자동 수락은 실패 위험과 시간 정책이 검증되기 전 기본 동작으로 넣지 않는다. 로그와 의뢰 상세에서 실패 이유를 알 수 있어야 한다.

## 가격과 상품 해금

호감도별 가격 변화 방향은 확정이나 곡선은 미정이다. 관계 단계별 혜택을 단순하게 보여주는 설계안을 둔다.

상품 해금은 관계 기준 + 관련 신규 도구 납품을 결합하는 제안이다. “호감도 60 및 정밀 대패날 납품 → 진열대”는 조정 예시다. 수리 반복만으로 모든 성장 상품을 해금하지 않게 한다.

한 번 해금한 상품은 관계 하락에도 영구 해금하고 가격 혜택만 바꾸는 방식을 권장한다. 이는 아직 확정되지 않은 정책이다. 일시 재잠금을 선택할 경우 구매한 장비나 시설까지 회수하지 않도록 별도 규칙이 필요하다.

## 피드백 연결

완료한 도구 공급은 사용 피드백 자격을 남긴다. 수리마다 항상 신규 연구가 발생하는 것은 아니다. 피드백의 새로운 발견·반복 보고 보상은 [경험 문서](EXPRIENCE.md)를 따른다.

## 검증 기준

수락 전 납기 정지, 납기 경계 시각 일관성, 보상/손실 1회, 재고 중복 납품 방지, 오프라인 관계 손실 정책, 해금과 현재 가격 분리, 관계 하락 후 회복 가능성을 확인한다.

## 연구를 위한 위험 선택 (2026-10-15)

[발견형 수리](DISCOVERY_REPAIR.md)에서는 수리 의뢰를 받아 낯선 구조를 분석할 수 있다. 고객의 납기를 넘기면 계약에 따라 보수 감소·호감도 하락이 가능하지만 **얻은 연구 단서는 보존**된다. 연구 선택 시 예상 시간·납기·관계 위험을 제시하고, 수락 전 거절에는 실패 불이익이 없다. 구체 손실 값은 밸런스 미정이다.
