# Craftables — 제작물

[아이템 체계](README.md) · [제작 규칙](../system/CRAFTING.md) · [NPC 관계](../system/NPC_RELATIONSHIP.md)

## 생활 도구

**확정:** 목공소·가죽세공소·농장 각각 고유 도구 3종, 총 9종. 상점마다 해금 상품 1종, 총 3종. 아래 개별 명칭과 연결은 이전 논의의 **콘텐츠 초안**이다.

| 상점 | 도구 3종 후보 | 성장 납품 후보 | 해금 상품 후보 |
|---|---|---|---|
| 목공소 | 톱날·대패날·목공 끌 | 정밀 대패날 | 고급 무기 진열대 |
| 가죽세공소 | 재단칼·가죽 송곳·금속 펀치 | 정밀 재단칼 | 장인의 작업 장갑 |
| 농장 | 낫·괭이날·삽날 | 강철 낫 | 고급 탐험 식량 꾸러미 |

성장 납품 후보는 해당 도구의 개선 제작물이다. 별도의 네 번째 고유 도구 계열을 자동 추가하는 의미가 아니다.

수리는 반복 수입을 제공하고, 신규 도구 제작은 상점 성장 퀘스트다. 수리 완료만으로 신규 도구 납품 조건을 대신 충족시키지 않는 설계안이다.

## 도구 공급과 해금

1. 관련 의뢰·연구·관계 조건을 확인한다.
2. 요구된 개선 도구를 제작하고 지정 NPC에게 납품한다.
3. 납품 사실을 저장한다.
4. NPC 피드백을 통해 도구 이해도·연구 진행을 얻는다.
5. 상점 해금 조건이 충족되면 상품을 구매할 수 있다.

해금은 무료 지급과 다르다. 해금 상품은 골드의 소비처다. 호감도와 특정 도구 납품을 함께 요구하는 방식은 설계안이며 구체 기준은 미정이다.

## 무기

**확정 방향:** 무기 디자인은 범위를 좁혀 제작한다. 단검은 3티어로 설계하고, 상위 유니크는 별도 디자인을 고려한다. 모든 단검을 1×2 슬롯에 강제하지 않는다.

| 요소 | 상태 |
|---|---|
| 소형 단검 10종의 실루엣 탐색 | 이전 아트 작업 범위, 전체 MVP 의무 수량 아님 |
| 3티어 | 단검 아트 방향으로 확정 |
| Common / Refined / Masterwork 명칭 | 제안 명칭 |
| 전체 60종×3티어 | 에셋 연구 제안, MVP 약속 아님 |
| 단검별 최종 명칭·레시피·성능 | 미정 |
| 무기와 탐험 장비 효과 연결 | 설계 확장, 수치 미정 |

무기 종류, 제작 품질, 카드 등급, 연구 단계는 별도 축이다. 3티어 아트가 카드 3등급 또는 무기 품질 3단계까지 확정하지 않는다.

무기 제작·진열 판매는 자동 판매 루프와 연결한다. 방문객이 물건을 구매하고 들고 떠나는 장면은 작은 대장간의 주요 시각 보상이다.

## 대장간 투자 상품

가구는 목공소, 작업 장비는 가죽세공소에서 구매하는 방향이다. 진열대·작업대·보관 가구, 장갑·앞치마·벨트 등은 후보다. 제작 가능 상품과 구매 전용 상품은 정의에서 구별한다. 모든 구매 상품을 대장장이 제작법에 넣지 않는다.

가구 3종·장비 3종은 초기 상점 패널의 시작 제안이다. 슬롯 증가·효율·보관량 효과는 조정 전이며 확정 수치가 아니다.

## 제작물 정의에 필요한 정보 — 설계안

ID, 도구/무기 계열, 레시피, 연구 조건, 제작 시간, 재료, 납품 가능 의뢰, 판매 가능 여부, 아트 참조를 기록한다. 품질·각인·티어가 도입되면 각각 별도 필드로 표현한다.

NPC가 도구를 사용한다는 사실은 납품·피드백 이벤트로 나타낸다. 도구 내구도·매초 사용·파손률 계산은 구현하지 않는다.

## 기본 제작품과 연구 기술의 구분

**초기 기본 제작 후보(기술 해금 불필요):** 몽둥이, 나무방패, 부엌칼, 갈퀴, 주방팬, 못 묶음. 기존 상점별 고유 도구 목표와 별개의 기본 물품이며, 기존 생활 도구를 삭제하지 않는다. 제작은 기술 숙련 XP를 제공하고 연구를 발견할 단서가 될 수 있지만, **기본 물품 자체는 연구 노드가 아니다**. 단검/메이스/창/화살촉/사냥용 활/철방패 제작법의 원리 연구 및 구체 수치는 [RESEARCH_NODES_V1.md](../system/RESEARCH_NODES_V1.md)를 따른다. 새 여섯 기본 품목은 현재 구현이 완료되었다는 의미가 아니다.

## 초기 생활 도구 → 무기 연구 매핑

[성장 시스템](../system/PROGRESSION.md)에서 Chef Kitchen Knife/Cleaver, Farmer Rake/Sickle, Leatherworker Punch/Awl, Carpenter Hatchet/Saw, Hunter Hunting Knife/Bow/Arrows의 기술 XP 및 연구 연결을 정의한다. 이것은 테스트용 얇은 콘텐츠 우선순위이며 기존 마을 상점당 3가지 고유 도구 목표를 대체하지 않는다.
