# Stackable Items — 스택형 아이템

[아이템](README.md) · [소비품](CONSUMEABLES.md) · [회복](../system/NEEDS.md)

## 결정과 범위

인벤토리는 Diablo식 다칸 퍼즐이 아니다. 무기 원본 **아트**의 96px 가변 슬롯과 실제 게임 보관 슬롯은 서로 다르다. 재료·음식·음료·카드 조각 등 반복 수집 아이템은 정해진 `max_stack`까지 스택한다. 같은 `item_id`와 호환 가능한 속성만 합친다. 실제 최대 스택 수는 밸런스 미정이다.

음식 창고는 재료·무기와 분리된 넉넉한 **스택형 식량 보관소**이며 최초 12칸은 조정용 예시다. 기본 음식은 기상 후 자동 소비한다. 음료를 보유하지 않아도 우물물은 언제나 무료다. 프리미엄 버프 음식을 자동으로 소모하는 동작은 기본 OFF.

## 아이템 분류

| 분류 | 스택 | 비고 |
|---|---|---|
| 광석·괴·목재·가죽 등 재료 | 예 | 가공/제련 단계마다 별 ID |
| 기초 음식·음료 | 예 | 수량 감소와 효과 적용 원자적 |
| 탐험 보급품·카드 조각 | 예 | 사용 시 예약/차감 |
| 완성 무기·장비 | 기본 아니오 | 품질·제작 이력·소유 차이 |
| Perk/Enhance 카드 | 정의별 선택 | 등급·예약 상태 다르면 합치지 않음 |

## 규칙과 검증

- `item_id`, `stack_key`, `quantity`, `max_stack`, `reserved`를 명시하고 수량을 음수로 만들지 않는다.
- 슬롯/스택을 초과하는 획득은 지급을 잃어버리지 않도록 거절/보류/추가 저장 중 정책을 별도 결정한다.
- 수리·제작·탐험에 예약된 수량은 다른 시스템에서 이중 사용하지 못한다.
- 분할·합치기·소비·저장 후 복원에 대해 원자성 및 총량 보존 테스트를 적용한다.
- 자동 식사와 탐험 보급은 같은 스택을 두 번 소비하지 못한다.

**미정:** 기본/상점/음식 창고 실제 칸 수, 품목별 최대 스택, 창고 꽉 참 처리, 자동 보충/자동 구매 정책.
