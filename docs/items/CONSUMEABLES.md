# Consumables — 소비품

[아이템 체계](README.md) · [탐험](../system/EXPEDITION.md) · [경제](../system/ECONOMY.md)

요청한 파일명 `CONSUMEABLES.md`를 유지한다.

**방향:** 농장은 식량과 기초 보급을, 주점은 음식과 탐험가 모집을 제공한다. 음식은 반복 골드 소비처이며 작업 장비·가구의 영구 효과와 구별한다.

## 범위

| 분류 | 사용 목적 | 상태 |
|---|---|---|
| 주점 음식 | 제작 또는 다음 탐험의 일시 효과 | 도입 방향, 효과·수치 미정 |
| 탐험 식량 꾸러미 | 탐험 준비·보급 | 도입 방향, 수량 미정 |
| 농장 식재료 | 보급 또는 음식 관련 재료 | 후보, 요리 시스템 구현 약속 아님 |
| 강화/각인 카드 | 제작 시 소모 | [카드 문서](../cards/ENHANCE_CARDS.md), 초기 도입 시점 미정 |

씨앗·가축을 구매해 농장을 경영하는 시스템은 제외한다.

## 음식 초안

이 목록과 수치는 **예시**이며 최종 밸런스가 아니다. 주점 음식 3종부터 시작하는 제안이 있다.

| 후보 | 효과 후보 | 적용 범위 |
|---|---|---|
| 따뜻한 수프 | 일정 시간 제작 속도 향상 | 대장간 작업 |
| 고기 파이 | 다음 탐험 보상량 증가 | 다음 파견 1회 |
| 구운 생선 | 다음 탐험 시간 감소 | 다음 파견 1회 |

이전에 제안된 +5%, 10분 등의 값은 확정하지 않는다. 음식이 없어도 기본 제작·탐험이 가능하도록 검토한다. 음식 섭취 장면은 시각 보상 후보다.

## 사용 처리 — 설계안

- 사용 전에 대상·지속 시간·효과·겹침 규칙을 표시한다.
- 적용에 성공한 명령에서만 소비하고 중복 입력을 방지한다.
- 다음 탐험 효과는 파견 시 확정해 저장한다. 귀환할 때 현재 버프를 다시 읽지 않는다.
- 시간제 버프는 [아키텍처](../../ARCHITECTURE.md)의 시간 정책과 동일하게 처리한다.
- 파견 취소·작업 취소 시 반환 여부를 명시해야 한다. 정책 결정 전 임의로 소비하지 않는다.

중복 사용 시 지속 시간 연장·교체·중첩 중 어떤 방식을 택할지는 미정이다. 자동 섭취·일괄 사용도 초기 필수 기능이 아니다.

## 해금 상품과 반복 소비

농장 해금 상품 후보인 고급 탐험 식량 꾸러미는 상품 접근이 영구 해금되어도 구매한 꾸러미 자체는 소비된다. 영구 해금, 소유 수량, 1회 효과 상태를 따로 저장한다.

## 미정

최종 음식 3종, 가격·지속 시간·보급 수량·효과 상한·반환 정책·오프라인 버프 경과 정책. 개별 값은 경제·탐험 플레이테스트와 함께 확정한다.
