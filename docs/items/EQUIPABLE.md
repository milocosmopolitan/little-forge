# Equippable Items — 장착형 아이템

[아이템](README.md) · [제작물](CRAFTABLES.md) · [카드](../cards/README.md)

## 확정 방향

제작한 무기·방어구와 작업 장비는 아이템으로 존재하되, MVP에서 디아블로형 인벤토리·풀 장착 시뮬레이션은 구현하지 않는다. **NPC가 구매한 무기와 같은 스프라이트를 손에 들고 퇴장하는 모습**이 우선적인 시각 보상이다. 방어구 착용 레이어는 이후 확장한다. 캐릭터별 완성된 무기 이미지를 중복 제작하지 않는다.

장비 아이템에는 안정적 ID, 제작법 ID, 재료/품질/티어, 소유 상태, 아트 참조와 grip anchor를 분리한다. 무기 디자인의 가변 96×96 아트 슬롯은 **보관 공간 크기와 무관**하다.

## 장착 대상별 경계

| 대상 | MVP | 향후 |
|---|---|---|
| 방문 NPC | 구매한 무기를 손에 들고 퇴장 | 단골이 재방문 시 기억 |
| 대장장이 | 장갑·앞치마·벨트 등 작업 장비 후보 | 효과/외형 슬롯 |
| 탐험대 | 제작 무기를 지급한다는 서사 방향 | 효과·반환·소유권 정책 |
| 방어구 | 판매 가능 아이템 | 투구·방패 후, 갑옷 레이어 |

**미정:** 장비 슬롯 수, 양손/보조손 규칙, 탐험가 장비 소유/회수, 장비 성능 공식, NPC 전신 장착 확장 시점. 무기 내구도 물리 시뮬레이션은 만들지 않는다.

## 시각 계약

공통 원본→장면 LOD/상세/기록 카드로 출력. 손잡이 앵커를 이용해 NPC 손에 부착한다. 원본 아트는 무기군별 96px 가변 슬롯이고, 코어 시각 티어는 Common/Refined/Masterwork 3단계다. 아트팩과 Unique는 별도 축이다. 품질 등급, 카드 랭크, 연구 레벨과 자동 동일시하지 않는다.

테스트: 스프라이트 참조 존재, 장착 앵커 유효, 판매 처리 정확히 1회, 애니메이션 재생/저장 복귀로 소유권 복제 없음.
