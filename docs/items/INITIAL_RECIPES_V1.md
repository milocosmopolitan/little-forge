# 초기 제작 레시피 v1

상태: **콘텐츠 설계안**, 구현 완료나 연구 해금 승인이 아님. 원칙: **원재료 → 재사용 부품 → 완제품 → 상위 완제품**. 일부 품목은 원재료에서 직접 제작한다.

## 원재료 → 부품
- 원목 → 몽둥이(직접 완제품) / 봉 / 판자; 나뭇가지 → 짧은 막대 / 화살대.
- 원목 + 송진 → 나무 손잡이; 원목 + 송진 + 가공가죽 → 가죽 감싼 손잡이.
- 철 주괴 → 칼날 / 넓은 칼날 / 송곳날 / 도끼날 / 괭이날 / 톱날 / 낫날 / 화살촉 / 창촉 / 가윗날.
- 철·청동 주괴 → 리벳; 철·청동·황동 주괴 → 결합구. 가공가죽 → 끈 / 스트랩 / 그립 / 보강재.
- 철 주괴 ×2 → 주방 팬(직접 완제품). 중간 pan_body 없음.

## 후속
- shortbow: 활대·활시위 신규 부품, ELA 연구.
- reinforced_shield: 나무 방패 + 방패 보스 + 결합구, 방어/결합 연구.
- magic_wand: **특수 원정 나뭇가지** + 마력 파편, 일반 wood_branch 사용 금지.

기존 [16개 연구 노드](../system/RESEARCH_NODES_V1.md)는 일반 제작 XP·기술 숙련·연구 XP·단서를 구분한다. 현재 기본 제작은 몽둥이·나무 방패·부엌칼·갈퀴·팬·못 묶음이며, 화살촉은 GEO-02/point_forging Lv.2 조건이 있다. 위 확장 레시피를 **전부 시작 시 해금된 것으로 해석하지 않는다**. 갈퀴/못도 기존 연구 경로에서 삭제하지 않는다.

기존 큐는 등록 시 투입재를 차감한다. 조합 미리보기는 무상태이며, 중복 차감/중복 보상 금지. 의뢰로 맡긴 NPC 물품은 분해·판매·소비 불가. 분해 보상과 취소 환불은 아직 미정.
