# Enhance Cards — 강화·각인 카드

[카드 개요](README.md) · [특전 카드](PERK_CARDS.md) · [제작](../system/CRAFTING.md)

**설계안:** 제작할 때 소비해 제작물에 추가 특성·속성을 부여하는 카드다. 이전 기획의 각인 카드에 대응한다. 완성 무기에 나중에 카드를 붙여 반복 강화하는 시스템까지 확정된 것은 아니다.

## 연구와의 관계

기본 무기와 도구는 연구·재료·레시피로 제작한다. 카드는 가능한 제작물에 선택적 변형을 주는 역할로 둔다. 미해금 제작법을 카드만으로 우회하지 않는다.

속성·마법 연구 분야는 장기 연구 방향이다. 특정 속성 이름·전투 피해·강화 확률·장비 파괴는 미정이다. 작업 도구에도 각인을 허용할지는 후속 결정이다.

## 제작 흐름 — 설계안

1. 레시피를 선택한다.
2. 호환되는 카드와 결과 미리보기를 보여준다.
3. 재료와 카드의 사용 가능 수량을 확인한다.
4. 작업 등록 시 카드를 예약한다.
5. 정한 소비 시점에 재료와 함께 소비한다.
6. 완료 시 카드 효과가 반영된 제작물 인스턴스를 생성한다.

예약된 카드는 합성·다른 제작에서 다시 사용할 수 없다. 등록 직후 취소·작업 시작 후 취소·제작 실패 시 반환 정책은 미정이다. 정책이 정해지기 전 소비 시점을 임의로 구현하지 않는다.

## 합성과 아이템 구분

같은 카드의 상위 카드 합성은 공통 카드 성장 방향이다. 강화 카드 등급이 무기의 3티어 아트와 같은 단계 수를 가진다는 뜻은 아니다. 완성 무기 인스턴스는 사용한 카드의 결과 특성을 저장하되, 소비된 카드 수량을 계속 소유한 것으로 남기지 않는다.

## 초기 범위

강화 카드는 첫 기술 POC 밖이다. 도입할 때는 한 제작물에 한 효과 등 작은 조합부터 검증하는 제안이다. 카드 슬롯 개수, 효과 중첩, 무기 품질 영향, 실패 확률, 최대 등급, 획득처·수량은 모두 미정이다.

## 획득 방향 확정 (2026-10-15)

Enhance는 **퀘스트 보상, Salvaging(소유 아이템의 분해), Repair(수리 과정)**에서 얻는다. 수리 의뢰가 매번 카드를 보장하지 않으며, 미지 무기 연구 수리에서는 연구 단서가 카드와 독립적으로 제공될 수 있다. 고객에게 맡겨진 무기는 명시적 승인 없이 분해할 수 없다. [발견형 수리](../system/DISCOVERY_REPAIR.md). 기존 희귀도·합성 랭크·획득률 숫자는 설계 후보로 유지한다.
