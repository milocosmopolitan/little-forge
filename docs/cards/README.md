# 카드 시스템

[홈](../../README.md) · [특전 카드](PERK_CARDS.md) · [강화 카드](ENHANCE_CARDS.md)

**확정된 방향:** Fallout처럼 동일한 카드를 합쳐 상위 카드로 성장시킨다. **구분 설계안:** Perk는 장착형 기술 카드, Enhance는 제작 때 소비하는 각인 카드다. 명칭 대응·합성 수량·등급 수·효과는 아직 확정되지 않았다.

카드 시스템은 파운데이션 POC 범위 밖이다. 이 문서는 이전 기획을 보존하며, 콘텐츠 MVP 필수 포함 여부는 [MVP](../mvp/README.md)에서 별도 결정한다.

## 카드와 다른 성장 요소

| 요소 | 역할 |
|---|---|
| 연구 | 무엇을 만들 수 있는가 |
| 이해도 | 해당 분야를 얼마나 이해하고 연구 기회를 발견했는가 |
| Perk 카드 | 어떤 제작 성향·효율을 선택하는가 |
| Enhance 카드 | 이번 제작물에 어떤 추가 특성을 부여하는가 |
| 작업 장비 | 캐릭터의 장기 투자 |
| 음식 | 시간 또는 사용 횟수 제한 보조 효과 |

일반 제작에 카드를 필수로 요구하지 않는 방향을 기본 설계안으로 둔다. 카드가 연구·재료·관계 시스템을 대신하지 않는다.

## 합성

사용자가 선택한 것은 **같은 카드를 합쳐 상위 카드로 만든다**는 방식이다. 아래는 구현 제안이다.

- 동일 카드 ID와 동일 등급을 재료로 사용한다.
- 이전의 동일 등급 2장 → 다음 등급 1장은 조정 후보이며 확정 수량이 아니다.
- 확률 없는 합성을 우선 검토한다. 합성 비용·최대 등급은 미정이다.
- 장착 중·제작에 예약된 카드의 합성 가능 여부를 표시한다.
- 보유 수량 감소와 상위 카드 생성은 하나의 상태 변경으로 처리한다.
- 최고 등급은 상위 등급이 없음을 표시하고 합성을 막는다.

서로 다른 카드의 무작위 조합, 유료 뽑기, 거래 시장은 현재 합의된 필수 시스템이 아니다.

## 획득과 콘텐츠

탐험 보상·진행 목표·떠돌이 상인 등은 획득처 후보다. 지급 주기·희귀도·무료 뽑기·카드 풀은 미정이다. 카드 획득을 수리 의뢰의 필수 재료 공급과 섞지 않는다.

## 데이터 설계안

card_id, 종류, 등급, 효과 정의, 설명, 아트 참조, 합성 규칙을 정적 카탈로그에 둔다. 소유 수량·장착 슬롯·예약 상태는 저장한다. 효과는 명시한 대상과 상한을 가진다. 같은 카드의 효과 중복은 정의로 제한한다.

## 도입 전 결정할 항목

첫 도입 시점, 장착 슬롯 수, 합성 필요 장수, 최대 등급, 획득처, 카드별 효과와 수치, 강화 카드 예약·반환 정책. 미정 항목을 임의의 확정 규칙으로 구현하지 않는다.

## 획득 경로 — 2026-10-15 확정

**Perk는 제작 경험 + 이해도/연구 성장으로 얻는다. Enhance는 퀘스트, Salvaging, Repair를 통해 얻는다.** 기존의 30분 무작위 카드 뽑기는 현재 핵심 획득 경로로 확정하지 않는다. 동일 카드 합성은 유지한다. 희귀도 3단계·합성 랭크 4단계·30종씩 60종·2장 합성은 이전 *제안*이며 최종 확정 수치가 아니다. Perk는 지속 장착, Enhance는 제작 시 소모한다는 분류 설계안을 유지한다.

처음 보는 무기를 연구하며 수리하면 납기 실패·관계 손실의 위험이 있지만 연구 단서는 유지된다. 카드 획득 여부와 제작법 획득은 별도이며, 카드가 없어도 기본 제작/수리는 가능하다. [발견형 수리](../system/DISCOVERY_REPAIR.md).
