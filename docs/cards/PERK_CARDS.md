# Perk Cards — 특전·기술 카드

[카드 개요](README.md) · [강화 카드](ENHANCE_CARDS.md) · [경험과 연구](../system/EXPRIENCE.md)

**설계안:** 장착한 동안 대장장이의 작업에 지속 효과를 주는 카드다. 이전 기획의 기술 카드에 대응시킨다. 개별 효과·슬롯·등급은 미정이며 파운데이션 POC에 포함하지 않는다.

## 역할

장갑·가구와 별개로 제작 성향을 선택하게 한다. 연구가 제작법을 여는 역할이라면 Perk는 이미 가능한 작업을 어떤 방식으로 수행할지 보조한다. 장착할 때마다 소비되는 카드가 아니다.

| 후보 카드 | 효과 방향 | 상태 |
|---|---|---|
| 기초 단조 | 기본 작업 효율 보조 | 콘텐츠 초안 |
| 정밀 가공 | 정밀 도구 제작 특성 보조 | 콘텐츠 초안 |
| 관찰하는 장인 | 이해도 획득 보조 | 콘텐츠 초안 |

이 이름·효과는 새 제안이며 확정 카탈로그가 아니다. 확률·보너스 수치를 지정하지 않는다. 카드가 없으면 튜토리얼 이해도 보장이 작동하지 않는 구조를 만들지 않는다.

## 장착 규칙 후보

1. 보유 카드와 사용 가능한 슬롯을 표시한다.
2. 효과 대상·등급·변경 후 차이를 보여준다.
3. 장착 변경 명령을 검증해 상태에 반영한다.
4. 이후 작업의 계산에 적용한다.

진행 중 작업에 장착 변경을 소급할지는 미정이다. 작업 시작 시 효과를 고정하는 방식을 우선 검토한다. 장착 변경을 반복해 같은 작업의 보상을 중복 받는 구조를 피한다.

## 합성 연결

동일 카드 합성 방향을 따른다. 장착된 카드를 재료로 쓰는 경우 명시적 해제·교체 정책이 필요하다. 합성 후 높은 등급을 자동 장착하는지는 미정이다. [공통 합성 규칙](README.md)을 별도로 복제하지 않는다.

## 구현 전 필요한 결정

장착 슬롯 수, 작업별 효과 범위, 동일 카드 중복 장착, 최대 보너스, 합성 수량·등급, 진행 중 교체 시점, 획득처. 실제 작업 장비·음식과 함께 경제 효과를 검증한 뒤 도입한다.

## 획득 방향 확정 (2026-10-15)

Perk는 대장장이의 **제작 경험·이해도·연구 성과**에 의해 지급하거나 해금한다. Repair/Salvaging을 무작위 Perk 주요 공급원으로 취급하지 않는다. 이전 30종 카드·3단계 희귀도·4랭크/2장 합성은 콘텐츠·밸런스 설계 후보이며 확정 수치는 아니다. [카드 개요](README.md), [연구](../system/RESEARCH.md).
