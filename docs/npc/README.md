# NPC와 마을

[홈](../../README.md) · [관계](../system/NPC_RELATIONSHIP.md) · [경제](../system/ECONOMY.md)

**확정 원칙:** 주민은 단순 판매자가 아니라 대장장이에게 도구를 맡기고 실사용 피드백을 주는 협력자다. 상점이 있는 NPC와 대장간을 방문하는 NPC가 모두 존재한다.

## 상주 NPC와 장소

| 장소·NPC | 플레이어가 구매 | NPC가 요청 | 피드백 방향 |
|---|---|---|---|
| 목공소·목수 | 가구·목재·손잡이 | 톱날·대패날·끌 등 | 절삭·균형·정밀도 |
| 가죽세공소·가죽세공사 | 작업 장비·가죽 | 재단칼·송곳·펀치 등 | 정밀도·날끝·마모 |
| 농장·농부 | 식량·보급·기초 재료 | 낫·괭이날·삽날 등 | 강도·충격·녹 |
| 주점·주인 | 음식·탐험가 모집 | 깊은 도구 성장 의뢰는 현재 범위 밖 | 소식·모집 안내 |

첫 세 상점은 각각 고유 도구 3종과 해금 상품 1종을 가진다. 개별 도구명은 [제작물 초안](../items/CRAFTABLES.md)이다. 주점에 같은 3종·1종 규칙을 자동 적용하지 않는다.

## 방문형 NPC

광부·사냥꾼·떠돌이 상인은 방문형 후보다. 물건 구매, 거래, 의뢰를 제공할 수 있다. 떠돌이 상인과의 재료 거래 방향은 이전 기획에 포함된다.

방문형 NPC마다 독립 상점·고유 도구 3종·연구 트리를 추가하는 것은 MVP 범위가 아니다. 외모·이름·방문 간격·대사 수는 미정이다.

주문·피드백을 확인하려고 반드시 해당 상점에 갈 필요는 없다. 의뢰함·장부로 자동 전달하는 설계안으로 두고, 상점 방문은 구매·관계·대화를 위한 선택으로 만든다.

## 공통 상점 UI

**수용된 방향:** 상인 아트워크와 얇은 목재 테두리·어두운 배경의 공통 프레임을 사용하되 건물 기능에 맞는 패널을 제공한다. 인물 이미지는 추후 다시 제작할 수 있는 초안이다.

| 패널 | 주요 콘텐츠 | 주요 행동 |
|---|---|---|
| 목공소 | 가구 / 재료 / 의뢰 | 구매·상세·수락 |
| 가죽세공소 | 작업 장비 / 재료 / 의뢰 | 구매·장비 정보·수락 |
| 농장 | 보급품 / 기초 재료 / 의뢰 | 수량 구매·보급·수락 |
| 주점 | 음식 / 탐험가 모집 | 음식 구매·모집 |
| 대장간 | 제작·연구·진열·의뢰 관리 | 작업 등록·진행 확인 |
| 마을 밖 | 탐험 준비·진행·결과 | 파견·정산 |

의뢰 탭 추가는 최신 의뢰 설계를 반영한 UI 설계안이다. 공통 헤더에는 NPC·관계 상태·가격 혜택을, 상품에는 가격·보유 골드·해금 조건을 표시한다. 잠긴 상품은 필요한 조건을 설명한다.

대장간은 일반 상점 구매 패널로, 탐험은 상품 목록으로 억지 통일하지 않는다.

## 지도 아트

지도 선택지는 8개다. 현재 기능명이 확인된 6개 외 2곳은 미정이다. 기본 지도 위 hover 컬러 오버레이는 건물·주변 흙·풀을 자연스러운 수채화로 표현한다. 상점마다 임의의 고유색을 지정하지 않는다. 기존 대장간 등 에셋의 색과 일치시킨다.

오버레이는 지도와 동일한 기준 좌표·영역을 사용해야 한다. 실제 픽셀 치수·클릭 영역은 원본 에셋을 가져온 뒤 검증한다.

## NPC 데이터 — 설계안

정적 정보는 NPC ID·거점·상점·의뢰 풀·피드백 풀을 가진다. 저장 정보는 호감도·납품 기록·해금 플래그·미처리 피드백을 가진다. 실제 도구 내구도·직업 숙련도·매초 생산량은 저장하지 않는다.

NPC 애니메이션·방문 연출과 의뢰의 논리 상태를 분리한다. NPC가 화면 밖으로 나가도 수락한 의뢰나 보상이 사라지지 않게 한다.


## 회복 아이템의 상점 역할 (2026-10-15)

[NEEDS](../system/NEEDS.md)에 따라 농부는 **저렴한 음식**, 주점은 **고급 음식과 음료**를 제공한다. 음식은 허기를, 음료는 갈증을 버프와 관계없이 회복한다. **우물에서 무료 물을 항상 이용할 수 있다**. 상점 관계가 나쁘더라도 기본 수분 회복을 막지 않는다. 피로 회복은 수면 역할이다.
