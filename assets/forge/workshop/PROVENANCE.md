# 대장간 기물·배경 제작 참고

2026-10-17 대화에서 내장 `image_gen`으로 생성한 기물 5종, 빈 배경, 배치 및 작업 동작 프리뷰다. PNG는 생성 결과를 바이트 그대로 복사했다. 실제 크기·알파 상태·SHA-256·생성 파일명은 [catalog.json](catalog.json)에 기록한다. 다음 파일은 **고해상도 생성 후보/연출 참고**이며 네이티브 에셋·검수 완료 애니메이션이 아니다. 부분 알파가 있는 후보도 그대로 보존했다.

연구대/분해대는 초기 3/4 기물 대신 정면형으로 수정한 버전이다. 배치 씬은 기물/캐릭터를 이미지 생성기로 다시 합성한 그림이며, 개별 PNG의 정확한 픽셀 합성이 아니다. 기물 시점과 화풍, 손 접점, 캐릭터 비율은 런타임 크기로 재검수해야 한다. 프리뷰의 일부 캐릭터는 원본보다 작고 단순하거나 픽셀 밀도가 다르다. 이를 캐릭터 디자인으로 채택하지 않는다. 화풍/비율이 달라져 지적받은 초기 정면·후면 시트도 기본 자세로 추가하지 않았다.

## 참조와 생성 의도

정체성·화풍 기준은 기존 [여성 원본](../../characters/female/source/reference.png), [남성 원본](../../characters/male/source/reference.png)과 해당 폴더의 현재 채택 네이티브 기본층이다. 대화에서 업로드된 `ChatGPT Image Oct 17, 2026, 09_00_18 AM.png` 및 `Cozy Fantasy Blacksmith Sprite(2).png`와 재첨부본을 참조했다. 기존 레이어를 이 후보로 덮어쓰지 않는다.

아래는 생성 요청의 **요약**이며 정확한 전체 프롬프트 기록이라고 주장하지 않는다.

- 기물: 캐릭터와 어울리는 따뜻한 목재·어두운 철·황동 색, 독립 투명 배경, 작업 가능한 접촉 면, 인물/무기 없는 단품. 모루·물통·화로는 캐릭터가 왼쪽에서 오른쪽으로 작업하는 구도.
- 연구대 수정: 수평 앞 모서리를 가진 정면 책상, 얕은 상판, 중앙 설계도, 한쪽 책과 잉크병. 뒤의 정면 캐릭터가 필기할 자리 확보.
- 분해대 수정: 정면형 보강 작업대, 중앙을 비우고 양옆 트레이와 오른쪽 바이스. 앞의 후면 캐릭터가 무기 종류를 가림.
- 배경: 작업 기물이 없는 목조/석조 대장간 내부, 왼쪽 창·도구걸이, 뒤 출입문, 오른쪽 수납, 넓은 바닥.
- 배치: 기존 빈 공간과 기물 감성 유지, 왼쪽 아래 연구대/정면 캐릭터, 왼쪽 뒤 분해대/후면 캐릭터, 오른쪽 화로·모루·물통.
- 동작: 망치질·담금질·가열·연구·분해를 5행 × 3키로 비교. 연구는 정면, 분해는 후면이며 특정 무기를 보이지 않게 함.

## 후속 제작 계약

[pose.md](../../../.agents/skills/human-character-gen/references/pose.md)의 NPC/플레이어 구분과 작업별 접점·가림·이벤트를 따른다.

네이티브 기물/레이어·물통 앞 테두리·화로 앞 입구·별도 효과는 아직 만들지 않았다. 캐릭터 정면/후면 네이티브 포즈와 연속 작업 프레임도 아직 없다. 소켓 좌표는 미측정이라 `null`이며 임의 좌표를 등록하지 않는다. 기존 `assets/manifest.json`에는 런타임 에셋으로 등록하지 않았고 기존 맵/대장간/플레이어 출력을 교체하지 않았다. 구조 메타데이터·파일 보존과 원본 화풍/접촉의 시각 검수는 구분한다.
