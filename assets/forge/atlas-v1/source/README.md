# Little Forge workshop atlas v1 — visual review candidate

The actual female and male character frames from the recorded commit were inspected before generation. Characters are copied from the repository and resampled by nearest neighbour at exactly 3/4: 128×160 → 96×120, pivot (64,140) → (48,105). Neutral alpha heights are 88 pixels for both. No character was regenerated.

workshop-atlas.png is a transparent 384×256 texture on a 32×32 packing grid. Tiles are multiples of 32; the silhouette need not fill its tile. Furnace 3×4, anvil 2×2, tub 2×2, workbench 4×3, counter 3×2 cells. JSON rectangles are [x,y,width,height] with top-left image origin. All sizes are final native pixels; do not apply another 0.75 scale to props. Larger source art was generated with the built-in image generator using actual character and motion reference sheets, then explicitly extracted, alpha-thresholded and packed. Native alpha is binary for crisp outlines. Furnishing shapes are review candidates.

The workbench is ONE physical prop. Research draws character → complete desk → canonical front hand layer. Salvage draws the SAME desk → back-facing character. The solid front closes the previous knee gap. Back/front textures exactly reconstruct each base tile; seams are not independently outlined. Use a silhouette derived from the complete tile, partition its outline by render depth, and keep outlines inside the station draw group.

preview-*-960x180.png and GIFs are OFFLINE composites over the existing repository interior background, not Bevy captures. They deliberately show multiple copies of one smith to compare work poses simultaneously. GIFs are contact/layout inspection sequences, not full animation qualification. contact-review.png shows male and female contact keys including both workbench sides. Source animation contact anchors are used at 75%; placements are rounded once to a native pixel. contact-evidence.json records exact and snapped origins and foot/furniture floor differences. Furnace/anvil/tub contacts are manual candidate anchors on generated art. Research uses a rear standing line 9px behind/up from the front floor and its own registration anchor, leaving the original character frame untouched; numeric registration does not establish visual contact accuracy.

Remaining review: nearest-neighbour 3/4 reduction necessarily drops some original pixels; both genders share one ratio but not identical poses. Quenching and workbench front masks use horizontal cuts, requiring runtime/tool-mask refinement for all intermediate frames. This pack does not claim locomotion Y-sort, outline depth, save/load, or Bevy runtime validation. Floor/contact offsets should be reviewed in the supplied composites before integration. Background untouched. No repository changes, PR or merge was performed.

Generation brief: five isolated warm muted pixel-art workshop fixtures matching canonical sprites; compact furnace, stump anvil, low quench tub, one closed-front research/salvage desk, plain customer counter; true transparent atlas, side-scroller camera, no characters/text/room, 32px tile packing and character visible height about88px.
