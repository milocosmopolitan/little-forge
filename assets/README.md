# Foundation assets

Original PNGs from the owner's `little-forge-assets.zip` (2026-10-15), generated in this project's art sessions and supplied for implementation. No third-party stock packs have been added. Redistribution/legal ownership review remains the owner's release responsibility; this is provenance, not a newly granted license.

`manifest.json` records original filenames, SHA-256, dimensions, atlas grids and normalized bottom-center anchors. Source PNG pixels are unchanged. Forge/building sources contain generous transparent margins. Character sheets are a 4×3 grid; smoke/fire use six horizontal frames. Nearest sampling is used. These high-resolution generated sheets are not a strict pixel-grid production atlas; animation alignment must be visually reviewed on native targets before release.

`visitor.png` uses the existing female character sheet temporarily for the first visitor loop; it does not define a new NPC identity. `iron_dagger` is a small procedural sprite shared by the display and hand attachment until dedicated weapon art is supplied. RGB furnace references are deliberately excluded from transparent compositing.
