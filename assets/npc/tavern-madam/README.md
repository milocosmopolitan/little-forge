# Tavern madam

[Animation preview](previews/animation.html) · [8 expressions](previews/expressions-8.png) · [Walking](previews/walk.gif) · [Giving a tankard](previews/give.gif)

8 expressions, nod, shake_head, give and six-key walk. All pose/frame canvases are 128×160; foot pivot (64,140). Approved neutral artwork, beauty mark and grip outline are preserved.

`animation.json` contains timing and the one give transfer event. `poses/recipes.json` contains complete base/equipment layers, sockets and drawing order. `atlas.png` and `atlas-manifest.json` contain the 23 baked authoring frames. Eye and mouth channels remain independent.

See [ANIMATION.md](ANIMATION.md) for rebuilding and scope, and `qa/` for structural, GIF, reproducibility and browser review evidence. Game runtime integration has not been performed.
