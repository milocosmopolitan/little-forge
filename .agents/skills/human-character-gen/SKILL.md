# Human Character Generation

[pixel-art-gen](../pixel-art-gen/SKILL.md)의 그리드·팔레트·외곽선 규칙을 적용한다. 이 문서는 사람 캐릭터의 정체성과 분리 제작 계약이다. `farmer2`의 얼굴·색 수·좌표를 다음 캐릭터에 복사하지 않는다.

## 필요한 문서 선택

- 새 레퍼런스: 이 문서와 [character-spec.yaml](references/character-spec.yaml)로 기준 포즈와 레이어 계약부터 잡는다.
- 표정·대사: [expression.md](references/expression.md). 눈·입 부품과 조합을 정의한다.
- 고개·팔·전신 동작: [pose.md](references/pose.md). 보행은 제작 전에 손발 위상 계약을 읽고, 신체 좌우·키별 반대 팔 스윙·통과 키를 명세한다.
- 게임용 패킹: [create-atlas.md](references/create-atlas.md). 레이어에서 합성한 뒤 패킹한다.
- 성능 검수: [sprite-optimization](../sprite-optimization/SKILL.md). 제작 레이어 수를 런타임 스프라이트 수로 강제하지 않는다.

필요한 문서만 읽는다. 명세 작성 요청을 전체 애니메이션 제작이나 런타임 교체 요청으로 확대하지 않는다.

## 새 캐릭터 시작

1. 참조를 정체성·비율, 화풍·팔레트, 표정·동작 역할로 구분한다. 사용자가 좋아한 표정 강도를 보존하되 이전 시트의 잘못된 체형까지 복사하지 않는다.
2. 명세에 실제 머리/얼굴/눈 치수, 눈 간격, 목 길이, 어깨·몸통·팔·허벅지 폭, 다리 길이, 피부·머리·수염색을 기록한다. 가려진 정수리나 손은 관찰값이 아닌 복원 부분으로 표시한다. 측정하지 않은 값을 참조와 일치한다고 기록하지 않는다.
3. 같은 축척·원점의 **완전한 장비 없는 언더레이어**와 중립 표정 하나를 만든다. 모자 아래의 반사광을 머리 고유색으로 오해하지 않는다. 머리색·체형은 새 인물의 참조에서 결정한다.
4. 같은 가시 높이·발 기준점의 전신 비교와 얼굴 확대를 확인한다. 머리를 키우거나 다리를 늘려 셀을 채우지 않는다. 얼굴 승인과 전신 승인, 구조 검사와 시각 검수를 구분한다.
5. 기준이 맞으면 부위 분리 → 표정 → 포즈 → 합성 프레임 → 아틀라스로 진행한다. 기준이 어긋난 상태에서 전체 시트를 다시 생성하지 않는다.

## 캔버스와 좌표

**이 저장소의 모든 사람형 NPC 애니메이션은 Grid B 8×10칸 = 128×160 네이티브 픽셀, 발 기준점 `(64,140)`으로 통일한다.** 동작이 작거나 도구가 없어도 `frames/`와 포즈별 출력 레이어를 96×128로 내보내지 않는다. 사용자가 다른 규격을 명시한 경우에만 그 규격을 적용한다.

기본층·눈·입·장비의 **제작 원본은 96×128**, 발 기준점 `(48,124)`을 유지할 수 있다. 이 원본에서 애니메이션을 만들 때 모든 층에 동일하게 **`(16,16)`을 더해 128×160에 배치**한다. 이미 128×160으로 등록된 층에는 여백을 다시 더하지 않는다. 원점은 `(0,0)`, x 오른쪽/y 아래다. 명세에는 제작 원본 규격과 `pose_canvas`를 구분해 기록한다.

초기 가이드는 머리 `y=4..47`, 상체 `48..79`, 하체 `80..123`이다. **레이어를 잘라내는 경계가 아니다.** 목·허리·손·수염이 넘어가면 보존한다. 실제 체형과 소켓은 인물별로 기록하며 농부의 넓은 체형을 모든 인물에 강제하지 않는다.

캔버스 통일은 **투명 여백과 좌표 이동**으로 처리한다. 그림·픽셀 밀도를 확대/축소하거나 프레임별로 자동 맞춤하지 않는다. 절대 소켓·피벗·trim offset도 `(16,16)`만큼 옮기되 이동 벡터와 클립 시간·이벤트는 유지한다. 128×160 밖으로 동작이 넘치면 배치와 포즈를 재검토하고, 캐릭터별로 임의의 캔버스를 만들거나 넘친 부분을 잘라내지 않는다.

애니메이션의 1배 미리보기는 128×160, nearest 4배는 512×640이다. 아틀라스의 `source_size`는 `[128,160]`, 원본 좌표의 `pivot`은 `[64,140]`을 기록한다. 제작 원본의 96×128 검수와 출력 프레임의 128×160 검수를 구분한다. 게임용 내보내기가 있으면 cell 크기·손/머리/발 소켓과 표시 배율도 함께 갱신해 화면에서 캐릭터가 작아지지 않게 한다.

## 기본층과 장비

- `head-base.png`: 완전한 정수리·뒷머리·헤어라인, 얼굴 외곽·피부·귀·코·수염·콧수염. 눈·입·모자는 제외한다.
- `eyes/<state>.png`: 눈동자·흰자·눈꺼풀·눈썹. 고정 눈썹도 기본적으로 눈 부품에 포함한다. 다르게 설계하면 소유 층을 명세하고 중복하지 않는다.
- `mouth/<state>.png`: 입선·입 안·필요한 치아·혀. 피부 직사각형이나 수염 전체 패치를 포함하지 않는다.
- `body/upper-base.png`: 목·팔·맨손·기본 셔츠. `body/lower-base.png`: 골반·다리·기본 바지·기본 신발.
- `equipment/`: 모자·앞치마·장갑·벨트·도구 등. 필요하면 앞/뒤 층으로 나눈다. 요청하지 않은 의상은 추가하지 않는다.

눈·입 자리를 투명하게 뚫지 말고 피부/해당 재질로 채운다. 표정은 항상 같은 기본층에 새 눈·입을 합성한다. 이전 표정 위에 덧칠하거나 피부색 사각형으로 지우지 않는다. 수염은 기본층에 고정하며 큰 입에 변형이 꼭 필요하면 별도 마스크·변형층을 명세한다.

장비를 끄면 그 아래 몸·머리·옷이 완결되어야 한다. 모자 쓴 원본의 머리 조각만 따거나 완전한 두상을 오래된 잘린 머리로 교체하지 않는다. 얼굴 이식은 **얼굴 내부와 필요한 눈·입만** 적용하고 완전한 언더레이어의 정수리·뒷머리를 유지한다. 가려진 부분을 마스크만으로 복원했다고 주장하지 않는다.

완전한 언더레이어의 전체 실루엣을 기본층 기준으로 삼는다. 장비 원본과 언더레이어의 몸 조각을 구역별로 섞어 기본 몸을 재구성하지 않는다. 독립 생성한 부위는 같은 좌표계로 등록하고 목·소매·허리·손·부츠에서 비교한다. 같은 해상도가 같은 등록을 의미하지 않는다.

네이티브 1px의 짙은 외곽선과 재질별 그림자를 구분한다. 몸의 윤곽 정리 과정에서 얼굴·눈·수염을 다시 바꾸지 않는다. 일괄 침식·세선화·명도 치환으로 검은 틈이나 재질 손상을 만들지 않는다. 앞치마 옆단과 도구집 끝은 별도 윤곽·길이로 읽혀야 한다.

## 합성과 손실 검사

기본 순서는 하체 → 상체 → 머리 → 눈·입이며 장비·앞손·소품의 순서는 포즈별로 명시한다. 단순 덧씌우기는 **불투명 픽셀만** 적용하고 투명 픽셀로 바탕을 지우지 않는다. 머리/팔이 움직이면 예전 위치의 부품을 교체하며 남겨 두지 않는다.

같은 포즈의 기본층은 재합성 시 분리 전 원본을 복원해야 한다. 겹침은 합성 순서까지 포함해 비교한다. 얼굴 내부를 바꿨다면 변경 마스크와 눈·입을 제외한 영역은 그대로여야 한다. 바탕의 불투명 픽셀이 기본/장비 합성본에서 사라지면 내보내기를 실패시킨다. 움직인 포즈는 해당 포즈의 완전한 바탕을 기준으로 검사하며 중립 실루엣을 강제하지 않는다.

이 검사는 원본 자체의 구멍이나 부정확한 장비 마스크까지 보장하지 않는다. 각 층 단독, 언더레이어, 표정 적용, 모자 없는 착용, 전체 착용을 밝고 어두운 배경에서 직접 확인한다. 머리·수염·손끝·목·겨드랑이·허리·앞치마 옆선·부츠를 본다. 장비층에 셔츠/피부 조각이 남거나 장비를 끄면 도구집/장갑 조각이 몸에 남지 않아야 한다.

## 납품 전

[명세 템플릿](references/character-spec.yaml)에 현재 범위와 실제 파일만 기록한다. 계획한 상태를 이미 존재하는 에셋처럼 등록하지 않는다. 실제 소켓·팔레트·복원 부위·레이어 순서·상태 ID·조합·시간·이벤트·빌드 명령을 남긴다.

pixel-art-gen 구조 검사, 전체 색 수, 정확한 nearest 미리보기, 바탕 손실 0개, 눈·입 이외 영역의 표정 간 불변성을 확인한다. 전신/얼굴 비교와 모자 토글 시각 검수는 별도로 수행한다. 재빌드가 같은 결과를 내고 미리보기도 갱신하는지 확인한다. 시각 픽셀과 불필요한 PNG 생성 시각 메타데이터를 구분한다.

보행은 같은 쪽 팔·다리의 반대 방향 움직임과 반대쪽 팔·다리의 앞쪽 동행을 확인한다. 접지·지지·통과·루프 경계를 장비 없는 상태와 착용 상태로 정상/저속 재생 검수한다. 정지 시트나 생성 프롬프트만 확인하고 완료로 보고하지 않는다.

원본·레이어·중간 합성·아틀라스를 보존한다. 빌더 입력을 명확히 하고 예전 진입점도 같은 빌더로 연결해 과거 후보가 최신 원본을 덮어쓰지 않게 한다. 캐릭터 제작은 기존 NPC 런타임/카탈로그 교체 권한을 의미하지 않는다.
