# 탐험 동작

이 문서는 탐험 전투 동작을 제작할 때만 적용한다. 현재 승인 NPC를 읽고
`pose.md`의 캔버스·신체 기준 좌우·레이어 소유권을 유지한다. 탐험 출력은
`assets/expedition/<character>/`에 두며 NPC 기본층을 덮어쓰지 않는다.

## 동작 레퍼런스의 역할

사용자가 준 동작 시트를 실제로 열어 준비·당김·조준·발사·회수의 자세를
분석한다. 정체성 원본은 승인 NPC, 동작 기준은 제공된 시트다. 시트의 다른
얼굴·체형을 채택하지 않지만, 정체성 보존을 이유로 동작 참고를 무시하지 않는다.
출처와 채택한 동작, 재사용한 부위, 복원한 부위를 명세에 구분한다.

## 활

- 준비, 들어 올리기, 당기기, 조준 유지, 발사 반동, 회수를 구분한다.
  키 수와 시간은 참조에 맞춘다. 6키 참고가 있다고 중간 이동이 불연속이어도
  그대로 채택하지 않는다.
- 활을 잡는 손과 시위를 당기는 손을 신체 기준으로 고정한다. 어깨·팔꿈치·손목·
  손·활 손잡이·시위 양 끝·화살 오늬를 키별로 등록한다. 당기는 손만 옆으로
  미끄러지는 다각형으로 팔꿈치 회전을 대체하지 않는다.
- 당기는 손은 조준 위치로 이동하고 팔꿈치는 뒤로 열린다. 활을 든 팔은 앞으로
  뻗는다. 화살 오늬는 발사 전까지 시위와 당기는 손에 붙고, 화살은 받침을 지난다.
  발사 후에는 화살이 떠나고 시위 복원과 손의 반동이 이어진다.
- 셔츠 소매·접힌 주름·장갑·손목·망토 가림을 팔과 함께 제작한다. 평평한 단색
  팔을 상세한 기존 의상 위에 얹어 완료하지 않는다. 기존 팔을 지운 몸 바탕과
  어깨/겨드랑이를 먼저 완성하고 이중 팔·끊긴 소매·빈 구멍을 확인한다.

## 단검과 다른 전투 동작

무기를 뽑기, 공격 준비, 타격, 반동, 회수를 구분한다. 손잡이 접점과 신체 기준
손을 유지하고 날 방향·가림을 키마다 확인한다. 피격은 몸의 반응, 후퇴는 이동
방향, 승리는 종결 자세로 읽혀야 한다. 기본 얼굴을 새로 그려 감정을 대신하지 않는다.

## 재생과 검수

공격은 이벤트 시작 시점부터 순서대로 진행하고 조준/회복에서 유지한다.
전역 시간의 나머지 연산으로 당김↔조준을 계속 왕복하거나 발사를 반복하지 않는다.
화살·충돌 연출은 시뮬레이션 사건을 표시하며 이미지 프레임이 피해·보상을 지급하지 않는다.

모든 키의 팔 단독, 의상 포함 바탕, 전체 착용본을 같은 원점으로 출력한다.
네이티브 1배와 정수 nearest 확대에서 밝은 배경과 어두운 배경을 모두 확인한다.
정상 속도와 느린 재생에서 연결·접점·실루엣·회수 끝을 본다. 정지 시트만으로
모션 검수를 완료했다고 하지 않는다. 최종 게임에서도 프레임 누락과 왕복 떨림을
확인한다. 구조 검사 통과, 재생 확인, 사용자 시각 승인은 별도 상태다.
