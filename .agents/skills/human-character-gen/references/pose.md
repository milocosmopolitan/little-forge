## 역할별 동작 세트

NPC와 플레이어 모두 **공통 기본 포즈·표정·동작 세트**를 갖는다. 명세의 `role`을 `npc` 또는 `player_blacksmith`로 정하고 공통 세트에 역할별 작업을 더한다. 플레이어 작업 5종은 공통 세트의 대체물이 아니다. 역할이 다르다는 이유로 원본 비율이나 공통 출력 규격을 바꾸지 않는다.

| 역할 | 공통 기본 세트 | 역할별 추가 작업 |
| --- | --- | --- |
| `npc` | `neutral`, `nod`, `shake_head`, `give`, `walk` + 공통 8표정 | 인물/직업별 작업이 필요할 때 추가 |
| `player_blacksmith` | NPC와 같은 기본 포즈·제스처·보행 + 공통 8표정 | `hammering`, `quenching`, `forging`, `researching`, `salvaging` |

공통 8표정은 `neutral`, `talk-small`, `talk-wide`, `talk-round`, `blink`, `happy`, `surprised`, `relaxed`다. 양 역할 모두 [expression.md](expression.md)의 눈/입 부품과 독립 깜빡임·말하기 채널을 사용한다. 공통 계약을 공유한다는 뜻이지 NPC의 얼굴·체형·완성 프레임을 플레이어에 복사한다는 뜻은 아니다. 한 요청에서 전체 세트를 즉시 제작할 필요는 없지만 미제작 상태를 명세하고, 역할을 이유로 플레이어 기본 세트를 제외하지 않는다.

`neutral`은 원본 오른쪽 3/4 기본 자세를 유지한다. 플레이어 작업 방향 기준으로 `front-neutral`(연구), `back-neutral`(분해)을 별도로 만든다. 이 둘은 공통 중립 포즈를 유지하면서 추가하는 방향별 기준 포즈다. 얼굴이 보이는 정면에는 해당 방향의 눈/입과 깜빡임을 제작한다. 후면에는 얼굴 눈/입 레이어를 합성하지 않으며 이는 플레이어 표정 세트를 생략하는 이유가 아니다. 공통 기본 포즈·보행 계약은 아래를 따른다.

원본/현재 채택 레이어를 **정체성·화풍·비율의 기준**, 작업 프리뷰를 **동작·구도의 참고**로만 사용한다. 프리뷰의 작은 머리/몸 그림을 새 캐릭터 기준으로 삼지 않는다. 머리/얼굴 크기·눈 간격·몸통/다리 길이·어깨 폭·앞치마 길이·픽셀 밀도를 측정해 같은 가시 높이에서 비교한다. 정면/후면 전환은 방향 변경이며 새 화풍이나 더 짧고 둥근 체형을 만드는 작업이 아니다. 기준 포즈가 어긋나면 다동작 시트 생성을 중단하고 한 포즈부터 수정한다.

## 표정과 분리

포즈는 머리 방향·목·어깨·팔·손·몸통·다리 위치가 달라지는 상태다. 눈·입만 바뀌면 [표정](expression.md)이다. 이전 expressions 시트의 고개 숙임·옆보기·팔 내밀기를 눈·입 변형으로 취급하지 않는다.

포즈마다 완전한 언더레이어, 기본층/장비, 눈·입 좌표계와 소켓을 갖는다. 같은 픽셀을 공유할 수 있는 층만 재사용한다. 회전한 얼굴에 중립 눈·입을 그대로 덮지 않는다. 평행이동은 부품을 함께 정수 이동할 수 있지만 원근·눈 간격·가려짐이 바뀌면 해당 방향의 특징을 별도로 제작한다.

## 공통 제작 순서와 시작안

NPC와 플레이어 모두 단계 1은 `neutral` 한 포즈와 8표정, 단계 2는 `nod`, `shake_head`, `give`, 단계 3은 `walk`다. 플레이어는 여기에 방향별 기준 포즈와 아래 대장장이 작업을 추가한다. 한 요청에서 전부 제작하라는 뜻이 아니다. `look-away`나 `present`는 필요할 때 추가한다.

- `neutral`: 원본의 시선·체형·서 있는 자세. 표정 기준 포즈다.
- `nod`: 기본 → 작게 숙임 → 최대 숙임 → 작게 숙임 → 기본의 5키. 초기 `[120,100,140,100,120]ms`, 비반복. 목 길이와 머리 부피를 보존한다.
- `shake_head`: 기본 → 왼쪽 회전 → 기본 → 오른쪽 회전 → 기본의 5키. 초기 `[100,140,100,140,100]ms`, 비반복. 얼굴을 좌우로 늘리는 변형으로 대체하지 않는다.
- `give`: 준비 → 팔 뻗기 → 소품 제시 → 전달 → 팔 회수 → 기본의 6키. 초기 `[120,120,180,120,120,120]ms`, 비반복. `transfer` 이벤트는 4번째 키에서 1회 발생하는 시작안이다.
- `walk`: 좌접지 → 좌지지/하강 → 우통과 → 우접지 → 우지지/하강 → 좌통과의 6키. 초기 각 120ms, 반복. 발 교대와 반대 팔 스윙, 마지막→처음 연결을 확인한다.

키 수·시간·전달 시점은 참조와 게임 연출에 맞춰 조정한다. 같은 시작/끝 이미지는 재사용하되 타이밍과 이벤트는 클립에 남긴다. 기존 런타임의 4프레임 가정에 맞추려고 보행 키를 임의 삭제하지 않는다.

보행 제작 전 아래 손발 위상 계약을 읽고 인물별 명세에 대응 관계를 기록한다.

## 플레이어 대장장이 작업

먼저 방향별 기준 포즈와 기물 높이/접촉점을 검수한 뒤 동작별 **준비 → 작업 → 회복 3키 프리뷰**를 만든다. 3키는 연출 검토용이며 게임용 프레임 수가 아니다. 본 제작에서는 준비·접촉·유지·회수·루프 연결에 필요한 키를 추가하고 실제 시간·반복 구간을 명세한다. 아래 키 수/시간은 시작안이며 이미 생성된 클립으로 등록하지 않는다.

| 클립 ID | 방향·기물 | 키 순서 시작안 | 재생 계약 |
| --- | --- | --- | --- |
| `hammering` | 오른쪽 3/4, 모루 | 준비 → 망치 들기 → 내려치기 → 접촉 → 반동 → 회복 | `[140,180,80,80,120,160]ms`; 접촉 키에 `hammer_contact`; 준비/회복과 작업 반복 범위를 구분 |
| `quenching` | 오른쪽 3/4, 물통 | 달군 날 접근 → 아래로 기울이기 → 입수 → 담금 유지 → 꺼내기 → 회복 | `[160,140,100,400,180,160]ms`; 기본 비반복; 입수/출수에 `water_enter`/`water_exit` |
| `forging` | 오른쪽 3/4, 화로 | 집게로 접근 → 날 삽입 → 가열 유지 → 가열 유지 변화 → 날 회수 → 회복 | `[160,180,300,300,180,160]ms`; 가운데 유지 구간만 반복 가능; `heat_enter`/`heat_exit` |
| `researching` | 정면, 연구대 | 설계도 보기 → 필기 접근 → 필기 A → 필기 B → 생각하기 → 설계도 복귀 | `[220,120,200,200,360,180]ms`; 필기 구간 반복 가능; 무기별 전신 포즈 불필요 |
| `salvaging` | 후면, 분해대 | 작업 준비 → 살짝 숙임 → 작업 A → 작업 B → 옆 트레이에 부품 놓기 → 복귀 | `[160,160,180,180,200,160]ms`; 작업 A/B 반복 가능; `parts_place`는 마무리 때만 발생 |

사용자의 화로 가열 작업 ID는 `forging`으로 유지하고 화면 설명에는 heating/가열을 쓸 수 있다. 물에 넣었다 빼는 동작은 `quenching`이다. `tempering`은 같은 물통 동작의 별도 중복 클립으로 만들지 않는다. 오타 `reseaching` 대신 `researching`을 사용한다.

- **망치질:** 한 손은 망치, 다른 손은 집게를 잡는다. 신체 기준 어느 손인지 명세하고 프레임 중 바꾸지 않는다. 집게는 모루에 놓인 날을 유지하며 망치 머리는 같은 타격점에 닿는다. 집게/망치 손잡이가 합쳐지거나 손이 타격점에 들어가지 않게 한다. 불꽃은 접촉 시 별도 효과다.
- **담금질:** 집게가 달군 작업물을 계속 잡는다. 날만 수면 아래로 들어가고 손/집게 손잡이는 테두리 위에 남는다. 회수 후 물방울과 열 변화는 별도 층으로 표현한다. 물통 깊이·앞 테두리 가림을 전 키에서 유지한다.
- **화로 가열:** 집게와 날을 화로 입구에 맞춰 수평 삽입한다. 손은 입구 밖에 있고 팔꿈치를 무리하게 펴지 않는다. 화로 몸체를 움직여 접촉 오류를 가리지 않는다. 불·숯·글로우는 몸 동작과 독립된 효과다.
- **연구:** 카메라 → 연구대 → 캐릭터 정면 순서다. 캐릭터는 책상 뒤에서 정면으로 작업하고 시선은 설계도로 내린다. 필기 → 생각하기로 차이를 표현한다. 책상이 하체를 가려도 얼굴·어깨·손은 읽혀야 한다. 정면 위에 기존 3/4 얼굴을 그대로 붙이지 않는다.
- **분해:** 카메라 → 캐릭터 후면 → 분해대 순서다. 캐릭터가 중앙 작업물을 몸으로 가린다. 작은 어깨·팔꿈치 움직임과 마지막 부품 옮기기로 표현한다. 특정 칼/도끼/활의 실루엣이나 분리 과정을 노출하지 않는다. 무기 종류마다 전신 애니메이션을 생성하지 않으며 대상은 작업 UI 아이콘으로 표시할 수 있다. 머리를 돌려 얼굴을 드러내거나 팔을 크게 벌려 가려진 작업물을 노출하지 않는다.

클립 이벤트는 소리·불꽃·물·완료 연출을 동기화하는 표식이다. 프레임 진입 때 1회만 발생시키고 정지/시크 시 중복시키지 않는다. 이미지나 `parts_place` 이벤트가 재료·골드·제작/분해 결과를 직접 지급하지 않는다. 결과는 게임 명령/시뮬레이션이 소유한다.

## 기물·방향·가림 계약

제작용 기물/배경과 최신 구도 프리뷰는 [`assets/forge/workshop/`](../../../../assets/forge/workshop/)의 `catalog.json`과 `PROVENANCE.md`를 읽는다. 이 고해상도 후보들은 네이티브 픽셀/소켓 검수를 통과한 런타임 에셋이 아니다. 원본을 보관하고 별도 네이티브·레이어를 만들며 기존 `assets/forge/*.png`와 `assets/characters/{female,male}`을 자동 교체하지 않는다.

| 기물 | 구도/작업 위치 | 분리할 가림·접점 |
| --- | --- | --- |
| 모루 | 캐릭터 오른쪽, 타격면 허리 부근 | `strike_point`, 집게의 날 고정점; 받침과 모루는 정적 |
| 물통 | 캐릭터 오른쪽, 손보다 낮은 앞 테두리 | 뒤 몸체/물 → 날의 수중 가림·효과 → 앞 테두리; `waterline`, 입수/출수 지점 |
| 화로 | 캐릭터 오른쪽, 집게를 뻗을 수 있는 입구 | 뒤 화로/불 → 날·집게 → 앞 입구 테두리; `opening`, `insertion_axis`, 손의 접근 한계 |
| 연구대 | 카메라를 향한 정면 책상, 캐릭터가 뒤 | 캐릭터의 온전한 바탕 → 책상의 하체 가림 → 설계도 위 앞손/펜; `writing_area`, 책·잉크병은 얼굴 옆 |
| 분해대 | 정면 책상, 캐릭터가 앞에서 등을 보임 | 책상/중앙 작업 구역 → 후면 캐릭터 → 필요시 손/부품; `work_area`, 좌우 `parts_tray`; 바이스는 중앙 밖 |

도구·무기·효과·기물은 캐릭터와 별도 제작한다. 화면 합성 순서를 포즈/프레임별로 명세하며 한 순서를 모든 기물에 강제하지 않는다. 연구·분해 모두 가려진 하체/몸도 완전한 레이어를 유지한다. 대장간 배경에 상호작용 기물을 굽지 않는다. 합성 씬 PNG는 배치 참고일 뿐 독립 레이어나 원본 비율 보존의 증거가 아니다.

기물은 캐릭터에 맞추며 캐릭터를 기물에 맞춰 프레임별 축소하지 않는다. 별도 기물 캔버스와 월드 원점/표시 배율을 기록하고 캐릭터 출력 128×160 안에 전체 화로나 책상을 우겨 넣지 않는다. 방향별 캐릭터 발 피벗과 기물 배치/카메라는 클립 중 고정한다. 방향이 다른 정면/3/4 기물은 실제 씬 시점과 함께 검수한다.

플레이어 제작 명세에 `role`, `action_set`, `direction_baselines`, 클립별 `station_id`, `facing`, `contact_points`, `occlusion_order`, `frame_duration_ms`, `loop_range`, `events`를 기록한다. 좌표는 실제 네이티브 에셋에서 측정하고 고해상도 프리뷰의 좌표를 그대로 복사하지 않는다.

게임 시뮬레이션 없이 독립 미리보기에서 양 캐릭터 × 5작업을 정상/저속 재생하고 프레임 시크·일시정지·재시작·루프 경계를 확인한다. 도구/작업물 교체, 장비 토글, 밝고 어두운 배경, 1배/nearest 4배도 본다. 모루만 확인하고 전체 검수를 완료하지 않는다. 정적 3키 시트만으로 접촉·시간·이벤트 검수가 끝났다고 보고하지 않는다. 기존 NPC 미리보기가 아직 새 플레이어 클립을 지원하지 않으면 미지원으로 기록하고 게임 연동 완료를 주장하지 않는다.

## 기본 보행의 손발 위상 계약

일반적인 양팔 스윙 보행에서 **같은 쪽 팔과 다리는 서로 반대 방향**, **반대쪽 팔과 다리는 함께 앞쪽**으로 움직인다. 신체 기준 왼발이 앞이면 오른팔이 앞·왼팔이 뒤이고, 오른발이 앞이면 왼팔이 앞·오른팔이 뒤다. 좌우 팔다리 이름이 다르다는 이유만으로 반대 위상이 맞다고 판단하지 않는다.

좌우는 **캐릭터 신체 기준**으로 고정한다. 화면 왼쪽 팔다리를 곧바로 캐릭터 왼팔/왼발로 부르지 않는다. 3/4뷰에서는 가까운 팔·다리와 먼 팔·다리가 각각 어느 신체 쪽인지, 버클·소매 같은 식별점이 어디에 속하는지 기록한다. 다리가 화면에서 교차하거나 좌우 반전되어도 같은 팔다리의 ID와 장비 소유 관계를 유지한다.

6키 기본안의 대응은 다음과 같다.

1. 좌접지: 왼발 앞, 오른발 뒤. 오른팔 앞, 왼팔 뒤.
2. 좌지지/하강: 왼발이 지지하고 오른발이 회수를 시작한다. 팔도 다음 교차를 향해 움직이며 이전 최대 스윙에 고정하지 않는다.
3. 우통과: 오른발이 지지 다리를 지나간다. 팔은 중간 위치를 지나 왼팔 앞·오른팔 뒤 방향으로 전환한다.
4. 우접지: 오른발 앞, 왼발 뒤. 왼팔 앞, 오른팔 뒤.
5. 우지지/하강: 오른발이 지지하고 왼발이 회수를 시작한다. 팔도 다음 교차를 향해 움직인다.
6. 좌통과: 왼발이 지지 다리를 지나간다. 팔은 중간 위치를 지나 오른팔 앞·왼팔 뒤 방향으로 전환하고 첫 키로 이어진다.

정확한 팔 각도·스윙 크기·정점 시점은 인물의 체형과 속도에 맞춘다. 통과 키의 중간 팔을 중립 휴식 자세로 대체할 때도 팔꿈치·손이 자연스럽게 이어지는지 확인한다. 다리 6키에 팔 극단 자세 2개를 앞 3키/뒤 3키로 단순 배정해 통과 키를 생략하지 않는다.

제작 순서는 팔다리 식별 → 키별 접지/지지/통과와 팔 전후 상태 기록 → 각 부위 제작 → 같은 키의 부위 합성 → 루프 재생 검수다. 상체와 하체를 별도로 생성한 경우 파일명이나 생성 프롬프트의 left/right를 신뢰하지 말고 실제 그림의 식별점과 관절 위치로 다시 연결한다.

납품 전 접지 2키뿐 아니라 지지·통과 키와 마지막→처음 전환도 확인한다. 장비 없는 합성본과 착용본을 1배/nearest 4배, 정상 속도와 저속 반복으로 재생한다. 정지 콘택트시트만으로 보행 검수를 완료하지 않는다. 손·발의 전후 위치는 어깨·골반을 기준으로 보고, 화면 x좌표만으로 모든 방향의 보행을 판정하지 않는다. 좌우 반전 시 접지·팔다리 ID·소품 소켓도 함께 확인한다.

관절/손·발 위치를 추적할 수 있으면 접지와 지지 키에서 같은 쪽 손·발의 상대 전후 이동이 반대인지 자동 검사하고, 통과 키에 이전 팔 극단이 남지 않는지도 검사한다. 이 수치 검사는 실루엣·타이밍의 시각 검수를 대체하지 않는다. 농부의 좌표·팔 소스 이름·버클 위치를 다른 캐릭터의 고정값으로 복사하지 않는다.

물건을 들거나 부상·의도된 특수 보행으로 한 팔을 고정하는 경우에는 해당 팔의 예외와 다른 부위의 움직임을 명세한다. 생성/합성 오류를 사후에 특수 보행으로 정당화하지 않는다.

## 얼굴 기본층의 윤곽

눈 제거는 피부 채우기이며 외곽 alpha 제거가 아니다. 옆 얼굴의 먼 눈이 실루엣에 닿으면 눈 자리와 얼굴 윤곽을 분리하고, 제거 전후 그 부위의 불투명 영역이 줄거나 깊게 파이지 않았는지 기본층 단독으로 비교한다.

## 부위·가림·소품

상하체·손·머리·장비는 같은 원점/축척으로 제작한다. 팔을 옮길 때는 예전 팔을 삭제한 완전한 몸 바탕부터 확보한다. 중립 상체에 새 팔을 얹어 팔이 두 개 남거나 겨드랑이가 구멍으로 남지 않게 한다.

포즈별 `neck`, `waist`, `eyes`, `mouth`, `left_hand`, `right_hand` 소켓을 기록한다. 손 소켓은 소품 접점이며 bbox 중심이 아니다. 소품 피벗과 뒤손 → 소품 → 앞손 순서도 기록한다. 팔이 앞치마 뒤를 지나면 앞/뒤 의상층이나 팔 분리가 필요할 수 있다.

모자·앞치마·장갑·도구는 부위 움직임과 가림에 맞춰 변형한다. 완성 전신을 매번 다시 생성해 수염·옷·장비 디자인이 바뀌지 않게 한다. 좌우 반전은 아트 정책이며 비대칭 도구집·소품이 어느 쪽으로 이동하는지 기록하고 앞뒤 손/전달 이벤트를 확인한다.

## 이동과 검수

모든 포즈의 출력 캔버스는 **128×160**, 발 피벗은 **`(64,140)`**이다. 96×128 제작 원본에서 온 레이어·절대 소켓에는 `(16,16)`을 한 번만 더하고, 포즈 이동 벡터는 그대로 유지한다. 보행 접지 발 x까지 중앙으로 강제하지 않는다. 초기안은 제자리 보행이며 월드 이동은 런타임이 담당한다. root motion을 쓰는 경우에만 프레임별 이동량을 명세하며 양쪽 이동을 중복 적용하지 않는다.

위치 변화는 정수 픽셀로 처리한다. 보간 회전/비정수 변형의 흐린 외곽선을 최종 PNG로 쓰지 않는다. 동작 크기와 무관하게 같은 128×160을 사용한다. 넘치는 동작은 배치와 포즈를 재검토하며, 프레임별 자동 맞춤·축소·잘라내기나 캐릭터별 임의 확장으로 해결하지 않는다.

각 포즈의 완전한 바탕과 분리층 재합성을 비교한다. 중립과 다른 실루엣은 정상일 수 있으므로 손실 검사 기준은 해당 포즈다. 1배/4배로 재생해 머리 크기, 눈·입 부착, 목·허리, 팔 중복, 수염·모자, 발 접지, 소품 접점·가림, 전달 이벤트 1회 발생을 확인한다.

산출물은 포즈별 부위 PNG, 소켓/합성 순서, 클립 상태 ID·시간·반복·이벤트, 비교 미리보기다. 최종 프레임은 레이어와 레시피에서 파생한다. 전달 이벤트는 이미지 중복 제거와 무관한 클립 정보다.

## 골반을 기준으로 숙이는 작업 동작

- 하체 접지와 골반을 기준으로 상체·목·머리·팔을 함께 숙인다. 머리를 화면에 고정한 채 몸통을 뒤로 빼는 합성은 금지한다.
- 어깨·목·허리가 연결된 완전한 자세 원본을 먼저 검수하고 부위로 분리한다. 분리 후 재합성은 원본과 픽셀 단위로 일치해야 한다.
- 기본 의상과 착용본을 각각 완전한 원본으로 유지할 수 있다. 이 경우 장비가 포함된 자세별 렌더링 변형임을 기록하고 교환 가능한 독립 장비층으로 표시하지 않는다.
- 도구를 지운 기본층은 그 뒤 피부·옷을 채운다. 도구 영역을 투명하게 삭제해 어깨·몸통에 구멍을 만들지 않는다.
- 생성 시트의 균등 셀 경계가 팔이나 도구를 가르면 전체 연결 성분으로 개체를 등록한다. 공통 배율로 전체 도구를 포함하고 프레임마다 체형을 맞춰 축소하지 않는다.
- 접지·부위 재합성·머리와 목 이동 자동 검사와 별도로 전 키를 정상/느린 재생, 기물 포함/제외, 밝은/어두운 배경에서 직접 본다. 재생 완료를 그림 완성 승인으로 기록하지 않는다.

### 자세 수정 시 얼굴 보존

- 동작이 좋아졌더라도 얼굴·화풍이 바뀌면 전체 시트를 채택하지 않는다. 승인된 중립 얼굴과 같은 가시 크기의 확대 비교를 남긴다.
- 같은 시선 각도의 머리를 재사용할 때는 머리·눈·입을 함께 정수 이동하고 목 접점을 따라가게 한다. 화면에 머리를 고정하는 방식과 구분한다. 눈·입만 따로 확대하거나 얼굴을 재해석하지 않는다.
- 정면·후면처럼 새 각도가 필요한 경우에만 승인된 원본에서 각도를 복원하고, 동작 시트의 달라진 얼굴을 정체성 기준으로 쓰지 않는다.
- 책상 앞 팔 층은 소매·팔꿈치·손목·손 전체를 포함한다. 피부색만 추출하면 책상에 가려진 소매가 사라져 손이 떠 보인다. 양팔의 소매와 피부가 모두 남는지 기물 합성 후 확인한다.

### 목·어깨 연결 회귀 방지

- 얼굴 피부 영역의 최하단은 턱·목·손이 섞인 값이다. 목을 잡을 때 사용하지 않는다. 실제 목 피부와 옷깃의 접점을 측정하되 목은 상체에 남긴다. 목 없는 머리의 고정 부착점을 그 몸통 연결부에 등록한다.
- 머리층을 수평으로 자를 때 원본 셔츠나 높은 어깨가 포함되지 않도록 한다. 장비 없는 상태와 착용 상태 각각에서 원본의 모든 셔츠 픽셀이 몸 층에 남는지 검사한다.
- 머리와 상체가 한 점 닿았다는 검사로 통과시키지 않는다. 턱 아래부터 옷깃까지 피부가 이어져야 하며, 이전 얼굴의 턱선이 목 안에 두 번째 검은 가로선으로 남아서는 안 된다.
- 얼굴 복원 후 책상 위에 다시 그리는 팔 층이 얼굴·목 피부를 덮지 않는지 검사한다. 손이 턱에 닿은 포즈도 별도로 본다.
- 시작 키, 가장 깊게 숙이는 키, 복귀 키를 포함한 전체 작업 키를 밝고 어두운 배경에서 확대 비교한다. 정체성 보존과 어깨 보존을 동시에 충족해야 한다.

### 움직이는 머리층의 소유권

머리 단독 확대에서 목 피부·셔츠·옷깃 조각을 확인한다. 기준 포즈의 목 연결용 픽셀이 머리 파일에 포함돼 있더라도 동작용 머리에는 따라붙이지 않는다. 얼굴·귀·머리카락·턱 윤곽은 보존하고 제외한 네이티브 픽셀 좌표를 명시한다. 중립 원본은 덮어쓰지 않는다. 눈·입은 정리한 머리와 동일한 정수 이동을 적용한다.

상체 단독에는 이전 머리·귀·턱 윤곽이 남아 있으면 안 된다. 작은 연결요소 삭제만으로 검사하지 않는다. 옷깃에 연결된 옛 턱선도 긴 검은 돌기로 남을 수 있다. 목 피부를 넓은 사각형으로 덧대지 말고 해당 자세의 좁은 목 영역으로 한정한다. 셔츠·어깨·옷깃은 원래 몸 좌표를 유지한다. 머리의 위아래 이동에 옷깃이 따라 움직이면 실패다.

머리 단독 → 상체 단독 → 두 층 합성 → 앞 팔·장비 합성을 같은 키에서 나란히 검수한다. 타격의 내려치는 키와 회복 키, 담금질의 시작·진입·최저점·루프 마지막 키를 포함한다. 목 외부 윤곽은 1px로 연결하되 피부 안에 가로선을 추가하지 않는다. 구조 검사는 이 시각 검수를 대신하지 않는다.

얼굴에 손을 댄 자세는 얼굴 피부와 손 피부가 한 연결요소가 될 수 있다. 장비 없는 같은 자세의 얼굴 범위나 별도 손 소유권으로 둘을 나누고, 얼굴 제거 후 팔·손 원본 픽셀이 남는지 검사한다. 연결요소 전체를 머리로 지우지 않는다.

### 목 연결의 재질 보존과 수면 가림

목을 연결하려고 주변 피부색을 가장 가까운 픽셀에서 가져와 다각형 전체에 채우지 않는다. 흰 셔츠 외에도 어두운 옷 주름·앞치마 끈·버클이 의상이다. 목 보정이 원래 비피부 픽셀을 피부로 바꾸면 실패다. 먼저 같은 좌표의 실제 목 피부와 의상을 보존하고 머리·몸통 등록을 고친다. 숙인 자세에서 목이 가려질 수 있으므로 노출 피부 픽셀의 최소 개수를 강제하지 않는다. 얼굴과 표정의 크기는 유지하면서 필요한 머리 위치 수정은 키별로 기록한다.

물 표면 전체를 캐릭터 앞에 불투명 합성하면 뒤쪽 물 위에 보일 도구까지 사라진다. 물 배경 → 수면 위 도구를 포함한 캐릭터 → 통의 앞면 순서를 쓰고, 도구의 잠기는 부분만 지정한 진입 경계에서 가린다. 수면 뒤쪽을 지나는 도구 픽셀이 실제 씬에도 보이는지 확인한다. 사각형 마스크의 좌표 검사만으로 실제 물 레이어의 가림을 검증했다고 판단하지 않는다.
