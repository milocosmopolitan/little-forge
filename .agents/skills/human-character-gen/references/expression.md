# 표정 제작

## 기준

표정은 **같은 포즈·머리 기본층에 눈과 입을 교체한 상태**다. 고개 회전·끄덕임·팔 동작은 [pose.md](pose.md)의 포즈다. 이전 `farmer/source/expressions.png`는 표정 강도와 동작 종류의 참조이며 몸·수염 손실·좌표·16칸 배열을 복사하는 원본이 아니다.

명세에 부품 ID, 눈썹 소유 층, 조합과 제작 범위를 먼저 적는다. 아래는 다음 제작의 기본 제안이며 새 인물의 성격/요청에 맞게 바꿀 수 있다. 계획한 부품을 사용 가능한 파일로 등록하지 않는다.

## 눈 5종과 입 4종

- 눈 `open`: 원본의 눈 크기·흰자·동공·시선을 보존한다.
- 눈 `half`: 반쯤 감은 눈. 세로만 축소하지 말고 눈꺼풀·동공 노출을 정리한다.
- 눈 `closed`: 깜빡임용 감은 눈. 눈썹은 기준 상태에 가깝게 유지한다.
- 눈 `happy-closed`: 웃는 곡선과 눈썹. 깜빡임 `closed`와 구별한다.
- 눈 `wide`: 놀람. 눈·눈썹 영역 안에서 커지되 얼굴 폭·코·수염·턱을 바꾸지 않는다.
- 입 `rest`: 원본의 편안한 기본 입. 원본이 미소라면 그 미소를 보존한다.
- 입 `small-open`: 작은 말하기. 1배에서도 기본 입과 구별되는 입 안을 확보한다.
- 입 `wide-open`: 큰 말하기. 필요한 입 안·치아·혀를 표현한다.
- 입 `round`: 둥근 입. 놀람/발음용이며 `wide-open`과 외곽 모양이 구별되어야 한다.

눈·입의 제작 원본은 몸과 같은 96×128 좌표에 특징만 담는다. 애니메이션 프레임과 포즈별 눈·입 출력층은 128×160이며, 원본을 `(16,16)`에 배치한다. 이미 출력 좌표로 등록된 층은 다시 이동하지 않는다. 부품 bbox별로 따로 중심 정렬하지 않는다. 소켓은 부착 좌표이며 자동 정렬 지시가 아니다. 런타임 trim은 [create-atlas.md](create-atlas.md)의 offset 복원 규칙을 따른다.

입은 수염 주변의 사용 가능한 피부 공간에 설계한다. 큰 입 때문에 수염을 지우지 않는다. 꼭 필요한 수염 변형은 별도 `beard/<state>`와 정확한 교체 마스크를 명세한다. 직사각형 얼굴 패치로 표정을 바꾸지 않는다.

## 먼저 만들 8개 조합

1. `neutral` = `open` + `rest`.
2. `talk-small` = `open` + `small-open`.
3. `talk-wide` = `open` + `wide-open`.
4. `talk-round` = `open` + `round`.
5. `blink` = `closed` + `rest`.
6. `happy` = `happy-closed` + `rest`.
7. `surprised` = `wide` + `round`.
8. `relaxed` = `half` + `rest`.

`happy`는 기본 입이 미소인 농부의 초기 레시피다. 기본 입이 무표정인 인물은 `smile` 입을 추가하는 등 조정한다. 이 8조합을 먼저 비교하고 눈 5×입 4의 20조합도 검수용으로 확인한다. 20조합 모두를 게임용 전신 이미지로 저장할 필요는 없다.

## 시간과 채널

- 깜빡임 시작안: `open → half → closed → half → open`. 중간 `half` 각 40ms, `closed` 80ms. 양끝 `open` 유지 시간은 idle 제어에서 정한다.
- 말하기 시작안: `rest → small-open → wide-open → small-open → round → rest`, 각 80~140ms. 실제 음성/텍스트 속도에 맞춰 조정한다.
- 깜빡임은 눈, 말하기는 입 채널에서 독립 재생한다. 놀람 중 자동 깜빡임은 기본적으로 잠시 중지하며 다른 우선순위를 택하면 명세한다.
- 자동 깜빡임 간격과 프레임 시간은 별개다. 무작위 간격을 사용하면 QA는 seed/고정 타임라인으로 재생한다. 명세 시간은 `duration_ms`로 통일하고 기존 런타임의 초 단위와 변환한다.

이 값들은 원본의 인상에 맞춰 조정할 시작안이며 고정된 감정/속도 규칙이 아니다.

## 검수와 산출물

같은 포즈의 머리·바디·장비는 표정 간 동일해야 한다. 변경 픽셀이 모든 상태의 눈·눈썹/입 범위를 합친 허용 마스크 안에만 있는지 검사한다. 피부 패치를 마스크로 넓게 허용해 검사를 통과시키지 않는다.

1배/nearest 4배, 밝고 어두운 배경에서 동공·시선·수염·턱·입 안을 확인한다. 모자 켜기/끄기, 감은 눈+말하기, 놀란 눈+말하기, 큰 입+수염 경계를 본다. 수염 고정 같은 구조 검사만으로 감정 가독성까지 합격이라 판단하지 않는다.

부품 PNG, 상태 ID·조합·시간·우선순위, 8표정 비교본과 20조합 검수본을 남긴다. 최종 아틀라스 프레임은 레이어 합성으로 파생하고 다시 생성하지 않는다. 고개 동작을 표정 제작 완료에 포함하지 않는다.
